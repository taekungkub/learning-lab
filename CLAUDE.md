# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repo purpose

`learning-lab` is a personal study repo — a collection of independent, self-contained
learning topics, each in its own top-level folder. It is not a single application.
Topics are unrelated to each other unless stated otherwise.

## Structure convention

Each topic folder follows this shape (see `drizzle-demo/` as the reference example):

```
<topic-name>/
  docs/          # study notes, checklists, Q&A written up as the topic is learned
  examples/      # runnable example scripts, numbered 01, 02, 03... in learning order
  README.md      # what the topic is, how to run it
```

When adding a new topic, follow this convention and add a link to it in the root
`README.md` topic list.
